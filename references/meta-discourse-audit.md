# MarxDoctorPaper 元话语与符号量化审计协议

博士论文篇幅长，元话语和模板化表达容易成批残留。本协议要求量化审计：给出计数和位置，不写"存在一定问题"这类模糊结论。

## 一、量化计数项

初稿完成后，全局统计并记录以下项目的出现次数和分布章节：

| 项目 | 示例 | 处置 |
|---|---|---|
| 自我叙述 | 本文 / 本章 / 本节 / 笔者 | 原则上删除，确需保留的每章不超过 1 处 |
| 匿名归因 | 研究者 / 有学者 / 有人认为 | 改为具体作者+脚注，或删除 |
| 设问导语 | 本节要回答 / 本节追问 / 那么……呢 | 全部删除或改写为陈述 |
| 因果封闭词 | 由此可见 / 因此顺理成章 / 这说明 / 可以看到 | 逐处检查是否因果跳跃，缺证据的改写 |
| 高频连接词 | 由此 / 正是 / 从而 | 计数并抽查，密度过高的章节重点改写 |
| 导游句 | 下一节将 / 如前所述 / 上文指出 | 正文内部全部删除 |

## 二、破折号专项

1. 正文段落原则上不使用双破折号"——"制造转折、补充解释或连接作者自造框架；
2. 必须区分：正文叙述中的破折号（清理）与**文献题名、引文原文**中的破折号（保留，不得为删符号改坏 GB/T 7714 著录信息）；
3. 直接引文中的破折号如必须规避，改为间接引述，并登记"因标点纪律改为转述"，不伪装成原文一致。

## 三、拟制概念引号专项

对全文引号包装的概念做三分：

1. **真实原文**：研究对象本人文字——保留引号，有脚注；
2. **已有历史/学术术语**：学界通行用法——可保留引号或去引号，保持全篇一致；
3. **作者临时分析标签**：如"时代—理论—实践""问题化""实践化""继承方法、重建答案"——能用普通句子表达的去掉引号；确需保留为分析概念的，先定义来源、范围和适用边界。

第三类是概念伪造和理论过度系统化的高发区，逐处登记处置方式。

## 四、长段落与段落功能混载

- 超过 800 字的段落列入审查清单，检查是否把引文、解释、理论归纳、历史评价、现实启示塞进同一段；
- 混载段落拆分：一段一个论证动作。

## 五、审计输出格式

专项审计报告按此格式：

```text
项目 / 总数 / 章节分布 / 典型位置（行号或可检索原文）/ 处置方式 / 复验结果
```

审计报告存审校记录目录，文件名带日期。回归审计时对照清零。

## 六、失败信号

- 审计只给印象不给计数；
- 清理后同一问题在相邻章节复发（说明只改了被点名的位置，没做全局）；
- 为清符号改坏文献题名和引文原文；
- 删除元话语后留下概念空缺（主语缺失、指代悬空）。
