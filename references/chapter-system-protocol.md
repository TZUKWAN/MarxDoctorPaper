# MarxDoctorPaper 章节系统协议

本协议规定博士学位论文的整体结构和各组成部分的写作规则。

## 一、标准结构

```text
封面 / 扉页 / 独创性声明 / 授权书
中文摘要 + 关键词
英文摘要（Abstract）+ Keywords
目录
绪论
第一章 ……第 N 章（主体 4—6 章）
结语
参考文献（若学校要求页下注+文末书目并用）
致谢
攻读学位期间成果 / 作者简历
```

各部分缺一不可。目录必须生成可见内容并写入 Word 缓存（见 `school-template-protocol.md`），不得只留 TOC 域。

## 二、绪论构成

绪论必须完成五件事，按自然论证顺序组织，不设"研究对象与概念边界"这类后台动作式独立标题：

1. **问题缘起**：从现实或理论语境抵达真正的问题；
2. **研究史述评**：分主题梳理既有研究，每类研究落到具体文献和脚注，最后指出既有研究在哪一环失效——这是全文脚注密度最高的部分之一，研究文献覆盖必须充分；
3. **核心概念**：界定本文使用意义上的核心概念，说明与相近概念的区分；
4. **方法与材料**：说明方法论进路和史料基础；
5. **结构安排**：简述各章任务。**禁止写成"第二章说明了……第三章分析了……"的复读式内容介绍**；应写各章之间的递进逻辑——为什么这一问题必须先解决，下一问题才成立。

## 三、章节规则

### 1. 章下小引言

每章开头、第一节之前安排一小段引言，只承担"引出本章要解决的问题"。

禁止：

- 章节自指与复述："第二章说明了……本章将……""上一章指出……本章……"；
- 预告式导游："本章分为三节，第一节……第二节……"；
- 把结论提前说完。

### 2. 各章功能边界

- 形成条件章：回答思想从哪些条件中生长出来，不提前展开核心内容；
- 思想演进章：回答阶段转折及其证据，不重复条件章材料；
- 核心内容章：回答思想"是什么"，做概念和命题分析；
- 理论分析章：回答"何以成立"，做逻辑结构和理论品格分析；
- 历史评价章：回答贡献与局限，评价必须有同期比较和证据尺度；
- 当代启示（如有）：必须限定在研究对象材料能够支持的范围内，禁止从人物文本直接跳到一般政策宣讲。

同一批史料在相邻章节重复承担同一论证任务，是结构失败信号。

### 3. 段落级硬规则

- 段首第一句禁止以"这一""这种""这些""上述""其""该""由此""因此"等指代或悬空因果词起句——必须出现明确主语和明确概念，防止偷换概念和概念漂移；
- 一句话最多一个脚注；一句需要多条文献支撑时拆句，不堆叠；
- 正文不得出现"（XX大学硕士学位论文，2008年）"这类身份括注；
- 小节内不设"本节追问""本节要回答"等导游句。

## 四、结语

结语做综合提升：回应绪论提出的问题，把各章判断收拢为对研究对象的整体理解，说明本文限度。禁止把前文框架（"提出问题—确立方法—组织传播"式）原样重复一遍。

## 五、标题纪律

- 标题不得使用问句和题目化提问腔（如何/何以/为何/为什么/怎样/是否/能否/吗）；
- 标题要有判断含量，不用"……研究""……分析""……探讨"这类无信息后缀堆满全部标题；
- 章、节、目三级层级清楚，不出现跳级。

## 六、字数分配参考

以正文 17—18 万字为默认总量（以学校规范为准）：

| 部分 | 参考占比 |
|---|---|
| 绪论 | 8%—12% |
| 各主体章 | 每章 12%—18%，各章体量大致均衡 |
| 结语 | 3%—5% |

任何一章超过全文 25% 或不足 8%，检查结构是否失衡。
