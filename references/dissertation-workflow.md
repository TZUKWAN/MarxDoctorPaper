# MarxDoctorPaper 博士论文生产主流程

本流程规定马克思主义理论一级学科博士学位论文从选题到交付的实际生产次序。博士论文与期刊论文的区别：篇幅长（正文默认 17—18 万字）、章节多（绪论+4—6 章+结语）、有学校模板和格式审查、有开题/预答辩/盲审节点。任何阶段缺少真实产物，不得假装进入下一阶段。

## 〇、前置：学校规范确认

动笔前必须向用户确认并记录：

- 学校/学院的学位论文写作规范文件（字数区间、章节要求、引注体例、模板文件）；
- 字数口径：正文是否含脚注、绪论结语是否计入；
- 引注体例：页下注还是文末参考文献，或两者并用；
- 模板文件：封面、扉页、独创性声明、授权书、致谢、作者简历的位置与格式；
- 查重率和 AIGC 检测的学校红线。

用户暂无法提供时，按本技能默认规格执行（正文 17—18 万字、页下注圈码每页重编号、GB/T 7714、结构见 `chapter-system-protocol.md`），并在交付说明中列出待用户按学校规范复核的事项。**模板中的个人信息占位字段不得虚构，保留空线并提示用户填写。**

## 一、选题与问题域

1. 明确研究对象：一个人物思想、一个理论问题、一段思想史或一个概念谱系，对象必须能被史料支撑。
2. 动笔前必须回答五个理论问题（见 EMARX `theoretical-problem-checklist` 精神）：
   - 本文要解释什么现象或问题？
   - 既有研究解释到哪一环，在哪里失效？
   - 本文的中心判断是什么？
   - 比已有研究多解释了什么（理论增量）？
   - 用什么材料和方法支撑？
3. 文献缺口诊断：运行 `scripts/emarx_literature_gap.py`，本地文献不足时自动触发内置 CNKI 检索。博士论文文献池应显著大于期刊论文，研究综述部分尤其需要覆盖足够的研究文献。
4. 涉及重大政策精神时，把政策语言转化为学术命题，不写成政策宣讲。

## 二、文献底座

博士论文的证据底座分四层，缺一不可：

1. **研究对象原始文献**：文集、全集、书信、日记、报刊文章，回到原文精读并记录卷册页码；
2. **经典文本**：马克思主义经典作家文本，按 `classic-text-reading-protocol.md` 精读，论证参与式进入；
3. **研究文献**：期刊论文、专著，用于研究综述和对话；
4. **学位论文**：按 `dissertation-source-mining-protocol.md` 当作待挖掘的文献库，追溯到原始来源，不直接依赖其二手归纳。

每篇锚定文献回到原文连续读取，保存页码或段落位置。拆解报告、摘要、工具输出只作索引，不替代原文。

## 三、开题结构

1. 按 `chapter-system-protocol.md` 搭建全文结构：绪论 + 4—6 章主体 + 结语。
2. 各章功能边界必须区分：形成条件、思想演进、核心内容、理论分析、历史评价各司其职，同一批材料不得在相邻章节重复使用承担同一论证任务。
3. 一级标题之间必须形成递进关系，前一部分产生后一部分的论证必要性；任意两章互换顺序后仍然成立，说明结构只是并列罗列，退回重搭。
4. 建立来源到论点映射和概念台账；大纲完成后调用 `agents/outline-reviewers/` 5 个 subagent 审查。

## 四、分章写作

1. 以小节（三级标题）为准入单元：每个小节先写论证卡，经 `agents/section-card-reviewers/` 审查通过后生成正文，正文完成后经 `agents/paragraph-reviewers/` 审查。
2. 段落级规则：段首不用"这一、这种、这些、其、该"等指代词起句；一句话最多一个脚注；每个自然段只承担一个清楚的论证推进。
3. 章下小引言短小引出本章问题，禁止章节自指（"第二章说明了……本章将……"）。
4. 每章完成后立即核验：脚注对账、标题—正文匹配、概念台账一致性。

## 五、深化扩展

字数未达标或论述深度不足时，按 `socratic-deepening-protocol.md` 做苏格拉底式中介问题追问，补实质分析。**禁止用空话、重复套话、无谓铺陈凑字数**；也禁止为凑字数新增无来源的事实和引用。

## 六、全稿审校

1. 走 `audit-then-fix-protocol.md` 两阶段：先只读审计产出量化问题清单，再逐项修复，最后回归审计。
2. 专项审计至少包括：
   - 脚注工程化：`scripts/footnote_audit.py`（一注一证、闭环对账、语义归并、书级著录）；
   - 元话语与符号：`meta-discourse-audit.md`（量化计数、设问导语、破折号、拟制概念引号）；
   - 绝对化表述：`absolute-claims-gate.md`；
   - AI 痕迹：`scripts/ai_trace_audit.py` + 保真编辑规则；
   - 政治合规：`political-compliance-protocol.md`；
   - 学位论文引用：`dissertation-source-mining-protocol.md`。
3. 大规模改写前建立基线备份，处理过度立即回退并声明作废版本。

## 七、交付

按 `school-template-protocol.md` 执行：

```bash
python scripts/emarx_build_docx.py paper.md paper.docx
python scripts/emarx_finalize_docx.py paper.docx --update-toc
python scripts/audit_docx.py --docx paper.docx --output docx-audit.json
```

交付前逐项确认：模板字段、目录缓存、批注修订清零、脚注对账、字数实测、页码抽查、PDF 视觉检查。交付报告必须列出实测数字和残余限制。
