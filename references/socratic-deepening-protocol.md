# MarxDoctorPaper 苏格拉底产婆术深化协议

博士论文的篇幅和深度来自对核心研究对象的层层追问，不来自铺陈和套话。本协议规定论述深化和字数扩展的正确方式。

## 一、核心方法：围绕对象的中介问题追问

以研究对象（如"某某的马克思主义文化观"）为圆心，对每一章的中心判断连续追问"这个判断要成立，必须先说明什么"。追问落在中层机制上，不停在宏大叙事或材料罗列两端。

常用的中介问题方向：

1. **转化链**：理论资源如何转为分析对象的方法？（接触—选择—改造—运用的具体环节）
2. **实践链**：观念如何转为组织、传播、教育等实践？实践如何回过来改变观念？
3. **关系链**：各理论品格/各内容要素之间是什么关系？并列还是相互规定？次序有无必然性？
4. **评价尺度**：贡献与局限按什么尺度衡量？同期比较对象是谁？证据到哪一层？
5. **断裂与连续**：早期思想与成熟思想之间的转折证据是什么？哪些延续、哪些断裂？

## 二、操作方式

1. 对每一章列出 3—5 个中介问题；
2. 每个问题回到史料找证据：能回答的写成论证段落；史料回答不了的，如实写"现有材料不能支持进一步判断"，不虚构证据；
3. 追问产生的分析必须接入上下文论证链，不是孤立的补充段；
4. 每轮深化后重新核验脚注对账和字数实测。

## 三、字数扩展的允许与禁止

字数不足时：

允许：

- 补中介问题的实质分析；
- 补史料细读（回到原始文本做更细的文本分析）；
- 补与既有研究的具体对话（指出某研究解释到哪一环、本文推进到哪一环）；
- 补概念的历史语义辨析。

禁止：

- 空话、套话、同义复述；
- 重复引用同一材料承担同一论证任务；
- 新增无来源的事实、数据和引用；
- 拉长破折号解释、堆砌修饰语；
- 把脚注和参考文献计入字数冒充正文达标。

## 四、字数压缩的允许与禁止

字数超标时：

允许：

- 压缩与核心对象无关的铺陈（背景生平复述、一般政策宣讲）；
- 合并重复论证；
- 把二手转述改回直接分析。

禁止：

- 删除论据保留判断（造成无证判断）；
- 删除限定语（把或然判断变成必然判断）；
- 删除脚注标记而保留引用内容。

## 五、失败信号

- 深化段与上下文没有论证关联，读者能看出是"补字数段"；
- 中介问题的回答没有史料支撑；
- 压缩后段落只剩判断没有论证；
- 字数统计口径在报告中不一致（正文/含脚注/总字符混报）。
